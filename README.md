# Sea Dragon (codename)

An alternate-history space race roguelike, 1957–1970. Run a space program, draft rocket part cards, fly risky missions, and make hard calls when things go wrong. Beat the rival to the Moon before Public or Congress support runs out.

Inspired by *For All Mankind*, the Sea Dragon rocket, FTL, Slay the Spire, XCOM, Reigns and Frostpunk.

## Status

Pre-prototype. The living design doc is in Claude Docs; `docs/design-summary.md` is a snapshot of the v1 decisions.

## Planned stack

- TypeScript + Vite, plain HTML/CSS
- Game rules separate from UI; content in data files
- Seeded RNG, saves in localStorage
- Balance bot that auto-plays runs
